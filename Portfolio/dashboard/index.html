system_info.sh

Gathers complete CPU, RAM, disk, OS release, and uptime diagnostics. Supports --json flag for API serialization.

resource_monitor.sh

Watchdog evaluating hardware thresholds (CPU > 80%, RAM > 85%, Disk > 90%). Logs alerts to logs/monitor.log.

Threshold Alert Daemon Ready ISO Logging

backup.sh

Generates timestamped tar.gz archives, verifies gzip checksums, and purges archives beyond a strict 5-backup retention limit.

Compression 5-Backup Retention Integrity Check

cleanup.sh

Safely purges temporary files (*.tmp, *.bak), Python bytecode, and deprecated logs. Features non-destructive --dry-run.

--dry-run Mode Cache Purge Root-Protected
